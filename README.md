# 유토리 프론트엔드 시안

React, TypeScript, Vite로 만든 모바일 우선 인터랙티브 디자인 시안입니다.

시작 화면에서 로그인 버튼을 누르면 계정 입력 없이 시나리오를 둘러볼 수 있습니다. ‘도착하지 않은 편지’ 대표 배너에서 예고편 팝업, 상세 화면, 영상과 미션 미리보기로 이동합니다. 프로필과 진행률은 예시 데이터입니다. 로그인 정보나 실제 위치를 수집하지 않습니다.

현재 본편 영상과 플레이 장소는 미지정입니다. 미션 화면의 지도는 예시 그림입니다. 실제 플레이 장소를 설정하면 상세 화면에 OpenStreetMap 삽입 지도가 표시됩니다.

## 로컬 실행

Node.js 24와 npm을 사용합니다. 프로젝트 루트에서 실행하세요.

```sh
npm ci
npm run dev
```

터미널에 표시된 주소에서 `/utory-prototype/` 경로를 엽니다.

## 검사와 빌드

```sh
npm run build
npm run preview
```

빌드 명령은 TypeScript 검사 후 정적 파일을 `dist/`에 생성합니다. 주소의 `#/` 뒤 경로가 현재 화면을 나타냅니다.
